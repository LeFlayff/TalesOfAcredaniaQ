Diese sind den [Fertigkeitsgruppen](Fertigkeitsgruppen.md) untergeordnet. 
Spezialisierungen werden werden auf dem Character Sheet immer so notiert, dass Sie fest einer Fertigkeitsgruppe zugeordnet sind. Sie haben keine eigenen Punkte, sondern verwenden die Punkte der Fertigkeitsgruppe + euren allgemeinen Wert.
